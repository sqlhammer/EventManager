## Unit Context

- **Stories**: Epic 7 — US-701..US-710
- **Design**: `aidlc-docs/construction/u9-read-api/functional-design/` (BR-READ-1..31, PBT properties P1–P6)
- **Project type**: brownfield — modify existing files in place, never create `*_new` / `*_modified` copies
- **Code location**: `backend/EventManager.Api/` and `backend/tests/EventManager.Api.Tests/`
- **Out of bounds**: `shared/`, `admin/`, `judge/`, `checkin/` — U9-CON-1 keeps this unit API-local
- **Dependencies**: existing read-model rows, `AppDbContext`, `CurrentUser`. No new package references.
- **Owns no database entity** — no migration is generated by this unit
- **Standards**: CS-1 (no ternary `?:`), FluentValidation for input, FsCheck.Xunit for PBT

### Key design constraints carried into code
- `Error.NotFound` — never `Error.Forbidden` — for insufficient tier, because
  `ApiControllerBase.Problem` maps Forbidden to 403 and **BR-READ-20 forbids 403 on read endpoints**
- ETag input is `(endpoint, eventId, watermark, tier, flags)`, hashed opaquely (BR-READ-22/23)
- No ETag on `GET /api/events` (BR-READ-25) or registrant detail (BR-READ-26, Q1=A)
